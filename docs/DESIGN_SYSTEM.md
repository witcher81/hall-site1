# מערכת עיצוב – Halls Hub

כל הדפים צריכים להשתמש בפלטה הזו (ולא ב־`slate`/`sky` כערכת נושא נפרדת).

## רקע וטקסט
- רקע עמוד: `#EFE6D5`
- טקסט ראשי: `#1A1A1A`
- טקסט משני: `#6B6560` / `#5F5F5F`
- כותרות מותג: `#0F3B2E`

## מותג
- ירוק ראשי: `#0F3B2E` (כותרות, כפתורי משנה כהים)
- ירוק משני: `#174D3B` (מעברים בגרדיאנט)
- זהב CTA: `#C9A227` עם `hover:bg-[#E5C96B]` או `hover:bg-[#b89220]`
- מסגרות כרטיסים: `#E0D4C3`

## כרטיסים
- `rounded-2xl border border-[#E0D4C3] bg-white shadow-[0_12px_40px_rgba(15,59,46,0.08)]`
- אזור משנה: `bg-[#FAF8F4]`

## שדות טופס
- `border border-[#E0D4C3] bg-white text-[#1A1A1A]`
- פוקוס: `focus:border-[#C9A227] focus:ring-2 focus:ring-[#C9A227]/40`

## כותרת עליונה (אתר)
- `header.site-header` עם `bg-[#0F3B2E]` (ראו `HomeHeader`, `DashboardNav`)

## הערה
קובץ `globals.css` משנה חלק ממחלקות Tailwind (`bg-slate-900` לבהיר). לכן **אל** לסמוך על `slate-*` לעיצוב כהה – להשתמש בצבעי hex מפורשים כמו למעלה.
